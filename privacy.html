Privacy Policy

Last updated: 2026-11-11

Scope

This policy covers the "Personal rclone client" Google OAuth application. The application is used only by its owner, through the open-source tool rclone, to access the owner's own Google Drive.

Data access

The application accesses Google Drive files and metadata of the signed-in account only to copy, sync and mount those files on the owner's own computer.

Data collection and sharing

No data is collected, stored on any server, sold or shared with third parties. OAuth tokens are kept only in the rclone configuration file on the owner's computer.

Revoking access

Access can be revoked at any time from the Google Account permissions page: https://myaccount.google.com/permissions.

プライバシー ポリシー(和文)

この application は, 所有者が rclone で自分の Google Drive を使うためだけのものです. Drive の file と metadata は, 所有者の computer への copy, 同期, mount のためだけに読み書きします. data を収集, server に保存, 販売, 第三者に提供することはありません. token は所有者の computer の rclone の設定 file にだけ置きます. 許可は Google account の設定からいつでも取り消せます.
